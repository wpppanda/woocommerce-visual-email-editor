Visual email editor for WooCommerce. Design transactional emails without editing templates.

== Description ==

WPP Email Editor, by WP Panda, is a visual editor for WooCommerce transactional emails.

Design each email — new order, processing, completed, refund, account, stock — with blocks instead of template overrides. WooCommerce keeps sending its own template until you turn a design on.

= Blocks =

* Header, heading, text, image, button, columns, divider, spacer, footer
* Order summary, order items, addresses, downloads, customer note
* Account action, stock notice, products, coupon, social, additional content, custom HTML

= Also =

* Brand kit: logo, colors, font, footer, social links
* Merge tags such as {order_number} and {customer_first_name}
* Preview against sample data or a real order, plus a test send
* Revisions, import and export
* Russian interface when the site locale is Russian

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/wpp-email-editor/`.
2. Activate WPP Email Editor.
3. Open WooCommerce → Email Editor.

WooCommerce 7.1 or newer is required.

== Frequently Asked Questions ==

= Will this replace emails I have not designed? =

No. A design is used only after you save it and switch on "Use this design".

= Does it work with High-Performance Order Storage? =

Yes. Compatibility is declared for custom order tables.
